Sheets to calculate and fill sample data automatically for lab diagnostics.
1. Select test type above the second grid and autofill will change accordingly.
2. Typing the sample number in its designated box will autofill the correct calculations for the testing.
3. Typing the sample number in the non-printing second grid will autofill the correct sample numbers to the end.
4. Delete the first sample after the final sample being run to remove and gray out the rest of the printout.
5. Print is set for the first two pages and done.
